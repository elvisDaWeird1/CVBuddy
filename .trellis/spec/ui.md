# UI Spec

`docs/ui-guidelines.md` is the human-readable UI reference.

## Summary

Use Tailwind CSS classes, CSS custom properties from `src/index.css`, and existing local primitives in `src/components/ui` before creating new styles or components.

## Rules

Keep UI work focused on the requested screen. Check loading, empty, error, and success states for interactive pages. Preserve responsive behavior and avoid redesigning unrelated screens.
