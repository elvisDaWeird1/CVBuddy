# Stitch Design Notes

Theme:
- Main color: soft blue
- Background: light gray/white
- Cards: white background, rounded corners, soft shadow
- Buttons: primary blue, rounded, full-width on mobile
- Inputs: rounded border, clear labels, helper/error text below

Layout:
- Auth pages: centered card, max width around 420px
- Profile pages: dashboard layout with left/sidebar or top nav
- Forms: vertical layout, clear spacing between fields
- Mobile: single column

Do not:
- Use dark theme
- Use overly colorful gradients
- Add complex animations
- Change API behavior
